# 💡 MindSparkAI: Your Learning Copilot

MindSparkAI is an interactive, AI-powered learning assistant designed to help students and self-learners master complex topics effortlessly. Built with Streamlit and powered by Google's Gemini 3.6 model, MindSparkAI tailors content to your learning style in real-time.

---

## 🌟 Key Features

* **Explain Simply**: Get clear, beginner-friendly explanations with real-world analogies.
* **Generate Quiz**: Practice and test your knowledge with instant custom quizzes.
* **Key Takeaways**: Extract bulleted summaries for fast revision.
* **Secure API Configuration**: Enter your own Gemini API key securely in the sidebar.

---

## 🛠️ Tech Stack

* **Frontend & Framework**: Streamlit
* **AI Model**: Google Gemini 3.6 (`gemini-3.6-flash`)
* **Language**: Python 3.x
